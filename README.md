# Yao Du HCI PhD Application Portfolio

Creative PhD application portfolio prototype based on the existing academic website, CV, research figures, and personal-life materials.

## Current concept

- Research-first narrative for HCI and Human-AI Interaction PhD applications.
- The homepage presents an early-career research trajectory from large-screen human-factors work to shared mental models, structured feedback, and feedback-data research.
- Project details open in accessible modal overlays with keyboard support.
- English is the default language; the main narrative and reports can switch to Chinese.
- Current work at Shokz is included briefly within professional experience without exposing internal interfaces.
- Personal interests appear as a single supporting line within the profile rather than a separate gallery or section.
- Responsive light and dark themes support desktop and mobile layouts.
- Thesis and paper figures are presented in English. Leadership-cockpit and driver-seat project images retain the original Chinese materials.
- Original Chinese thesis figures remain archived under `assets/v2/to-translate-cn`; the live site uses the English set under `assets/v3/english-figures`.

Open `index.html` to preview locally.
